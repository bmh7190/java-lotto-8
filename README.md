# java-lotto-precourse

## 입출력

### 입력

입력함수로 얻은 값은 입력만 하고, 객체 생성은 다른 곳에서 한다.

1. 로또 구입 금액 입력

    * 숫자인지 검증
    * 1000원 단위인지 검증
    * 0원 이하인지 검증
    * 구매 개수 = 금액 / 1000


2. 당첨 번호 입력

    * 쉼표 기준으로 구분
    * 6개인지 검증
    * 1~45 범위인지 검증
    * 중복 아닌지 검증
    * 숫자형인지 검증


3. 보너스 번호 입력

    * 1~45 범위인지 검증
    * 당첨 번호와 중복되지 않아야 함
    * 숫자형인지 검증

### 출력

출력 함수는 계산된 값을 전달받아 "출력"만 담당한다.

1. 구매 개수 출력


2. 구매한 로또 번호 출력 (각 로또는 오름차순 정렬)


3. 당첨 내역 출력

    * 3개, 4개, 5개, 5개+보너스, 6개 순서로
    * 예) `3개 일치 (5,000원) - 1개`
   

4. 수익률 출력

    * 서비스에서 계산한 값 출력
    * 소수점 둘째 자리 반올림
    * 예) `총 수익률은 62.5%입니다.`
   

5. 예외 상황 출력

    * `[ERROR]`로 시작
    * 예외 발생 시 메시지 출력 후 종료

## 로또 서비스

1. 당첨용 로또 생성 (WinningLotto)

    * 6개 + 보너스
    * 1~45 사이의 중복 없는 숫자


2. 사용자 로또 생성 (UserLottos)

    * 입력받은 구매 개수만큼 로또 번호 생성
    * 각 로또는 `Lotto` 클래스 사용
    * 번호 6개 중복 없이 생성


3. 당첨 내역 계산

    * 각 로또마다 당첨 번호와 비교해 일치 개수 계산
    * 보너스 번호 일치 여부 포함
    * 등수(`Rank`) 계산
    * Rank별 개수 집계


4. 등수(Rank) 정의

    * 3개 일치 (5,000원)
    * 4개 일치 (50,000원)
    * 5개 일치 (1,500,000원)
    * 5개 + 보너스 (30,000,000원)
    * 6개 일치 (2,000,000,000원)
    * 나머지 꽝(MISS)


5. 총 상금 계산

    * Rank별 개수 × Rank 상금
    * 모든 상금 합산


6. 수익률 계산

    * (총 상금 / 구입 금액) × 100
    * 0 나누기 방지
    * 계산은 서비스에서, 반올림은 출력에서

---

## 예외 처리 규칙

1. 입력이 숫자가 아님
2. 구입 금액이 1000원 단위 아님
3. 당첨 번호 개수가 6개가 아님
4. 번호가 1~45 범위를 벗어남
5. 당첨 번호 중복
6. 보너스 번호가 당첨 번호와 중복

---

## 구조 설계

* **InputView** : 입력 전담
* **OutputView** : 출력 전담
* **LottoService** : 로또 생성, 당첨 결과 계산, 수익률 계산
* **Lotto / WinningLotto / Rank / UserLottos** : 도메인 객체
* **Controller** : 입출력과 서비스 연결
